## 2. Mode 1 — KPI・セグメント深掘り

### 結論
数字から見た収益力、変化点、弱点を先に示す。

### 年次業績推移

| 年度 | 売上高 | 営業利益 | 経常利益 | 純利益 | EPS | 配当 |
|---|---:|---:|---:|---:|---:|---:|
| | | | | | | |

会社開示の会計指標に合わせる。IFRS等で経常利益が存在しない場合は無理に作らない。

### 利益率・資本効率

| 年度 | 営業利益率 | ROE | ROIC | 自己資本比率 | 営業CF | FCF |
|---|---:|---:|---:|---:|---:|---:|
| | | | | | | |

ROICやFCFは算定方法が不明確なら定義を明示するか省略する。

### セグメント

| セグメント | 売上高 | 構成比 | 利益 | 利益率 | コメント |
|---|---:|---:|---:|---:|---|
| | | | | | |

確認観点：

- 売上を支える事業
- 利益を支える事業
- 赤字・低採算事業
- 成長事業と成熟事業
- 会社の注力領域と実績の整合

### 直近四半期の進捗

| 指標 | 直近実績 | 通期計画 | 進捗率 | 前年同期比 | コメント |
|---|---:|---:|---:|---:|---|
| | | | | | |

季節性が強い場合は単純進捗率を過大評価しない。

### 業種固有KPI

必要な場合だけ追加する。

外食・小売：既存店売上、客数、客単価、店舗数、FC比率、原材料費、人件費率

製造業：受注、受注残、稼働率、原材料価格、為替感応度、設備投資

不動産：契約・引渡、在庫、用地、金利影響

IT・サービス：ARR、顧客数、ARPU、解約率など

### 数字から見た強み / リスク
各3〜4項目以内を目安にする。

### 未解決点
重要だが確認できなかった項目だけ示す。

## 4. Mode 3 — ニュース・開示 × 経営方針

### 結論
直近で最も重要な変化を先に示す。

### 直近イベント

| 日付 | 種類 | 内容 | 業績への含意 | 根拠 |
|---|---|---|---|---|
| | 決算 / 適時開示 / IR / 報道 | | | |

原則60〜90日を中心にし、必要なら期間を広げる。

### 経営方針

- 会社が重視しているテーマ
- 成長戦略
- コスト対策
- 投資方針
- 株主還元
- 中期計画との整合性

### 事象 → 原因 → 含意

| 事象 | 背景・原因 | 業績への含意 | 次に確認すべき情報 |
|---|---|---|---|
| | | | |

### ポジティブ材料 / ネガティブ材料
確認済み事実と仮説を混同しない。

### 今後見るべき開示
次回決算、月次、中計更新、業績修正、配当方針など、対象企業に重要なものだけ示す。

## 5. 複数指定

### `1+2`
KPI・セグメント → 進捗 → シナリオ → バリュエーションの順に統合する。

### `1+3`
KPI・セグメント → 直近開示 → 数字への影響の順に統合する。

### `2+3`
直近開示・経営方針 → 将来シナリオ → バリュエーションの順に統合する。

### `1+2+3`
すべてを統合するが、重複表を作らず重要論点を優先する。

## 6. 追加オプション

### `比較も`
同業比較を追加する。比較会社の選定理由を短く示す。

### `DCF重視`
Mode 2のDCF、FCF、ネットデット、株式数、感応度を優先して追加調査する。

### `ニュース重視`
Mode 3の直近開示・重要報道を重点的に調査する。SNSや掲示板の噂を重要根拠にしない。
