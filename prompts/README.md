## 追加ルール

新しいプロンプトを追加するときは、原則として次の順で配置します。

```text
prompts/<category>/<prompt-name>.md
```

ファイル名とカテゴリ名は英小文字の `kebab-case` を使用します。

詳細は [リポジトリ構成ルール](../docs/repository-structure.md) を参照してください。
