# Museへ最初に渡す指示文テンプレート

下のテンプレートをコピーし、角括弧の部分を自分の内容に書き換えて、ZIPと一緒にMuseへ渡してください。ファンドは後から追加・変更できます。架空の記入例は `config/funds.example.json` にありますが、推奨値ではありません。

---

添付ZIPの README.md と SPEC.md に沿って、私専用の投資統合ダッシュボードを Muse のスペースとして作ってください。

私が監視するファンドは次のとおりです（買い増し条件も含みます）：

- ファンド名：[名称]（コード：[投信コード等]）
- NAV出典：[公式ページ・必要に応じて代替出典]
- 第1段階：[条件タイプ・閾値・観測期間・必須条件]、予定額：[金額または未設定]
- 追加段階：[必要な場合のみ同様に登録]

条件タイプとパラメータは SPEC.md の型カタログを参照してください。未記入の値を推測で補わず、未登録のファンドは監視しないでください。`config/funds.example.json` は架空の構造例であり、その値を実運用へ自動登録しないでください。


進め方：
1. まず所有者限定の画面、永続保存、ジョブと所有者の権限分離、決定的な計算、定時起動と報告が、あなたの環境で実現できるかを条項ごとに対応表で示してください。本番への書込・公開・cron登録は、私が確認するまで保留してください。
2. 次に空DBの試作を作り、合成データの計算テスト（期待値との照合）を全部通してください。合成データを本番に保存しないでください。
3. 出典レジストリ（系列ごとの定義と取得経路）を作って私と確認してから、実データの取得を始めてください。定義の違う代理値で置換しないでください。
4. 実データは最初は日次1枠だけで照合し、結果を私が確認してから定期ジョブを登録してください。

台帳（自分の注文・約定の状態）は私が後から登録します。それまでは購入候補の提示は保留し、判定値の表示だけにしてください。売買の実行はしないでください。
