# 投資統合ダッシュボード Muse移植キット（配布版）

自分の投資信託の「買い増し条件」を毎朝チェックし、週次の市場分析とあわせて1つの非公開ダッシュボードに貯める仕組みを、Muse（スペース＋定期ジョブ）で再現するための仕様キットです。

**版：kit-1.0（2026-11-25）**

## 配布用データと利用者の個人情報

- 公開対象のファイルには、作者の保有・監視ファンド名、実際の投信コード、約定価格、購入金額、取引履歴、実データ、個人固有の買い増し条件を含めないようにしています。
- 監視対象は利用者が登録します。`config/funds.example.json` は、架空の名称・コード・金額・条件の組み合わせを使った独立した記入例であり、推奨値や初期運用設定ではありません。架空コードでの実データ取得や実運用への自動登録は行いません。
- 登録したファンドや台帳は、利用者の非公開Muse環境に保存する設計です。作者への送信機能は設けません。ただし実際のデータ保護は利用環境の権限設定・サービス仕様に依存するため、導入時に確認してください。

## 系譜（このキットの位置づけ）

前身の「[週次グローバル市場モニター](../weekly-global-market-monitor.md)」（PC／Python環境での市場分析を想定した公開プロンプト）の週次市場分析を土台に、日次の買い増し条件チェック、永続保存、所有者専用のダッシュボード、定期ジョブを統合したMuse向け発展版です。旧版はそのまま利用できます。Pythonコードを移植した完成アプリではなく、Museに実装させるための仕様・プロンプト集です。

|項目|旧版（PC／Python等）|Muse版|
|---|---|---|
|週次市場分析|主要10市場・警報・地域比較|分析手法を継承し履歴・前週比較を保存|
|日次の買い増し条件|対象外|利用者が登録したファンドを条件別に判定|
|表示・履歴|週次レポート中心|4タブの対話型画面・グラフ・履歴・台帳|
|定期実行|実行環境側で設定|Museの定期ジョブを想定（時刻は利用者の環境で設定）|
|個人情報|個人の保有情報を分析しない|日次は本人の登録情報を使用。週次は個人情報から独立|

## 必要な環境と使い方

Museで非公開スペース、永続保存、定期ジョブ、公開市場データの取得、決定的な計算が可能であることが前提です。各機能の利用可否は契約・環境によって異なります。実装前に対応可否を確認し、不足する機能は未対応として扱ってください。売買の自動執行は行いません。

1. GitHubからこのフォルダ内の8ファイルを取得し、フォルダ構造を保ってZIPにまとめる（リポジトリ全体をDownload ZIPで取得し、このフォルダだけ取り出しても可）。
2. ZIPを自分のMuseに渡し、`PROMPT.md` の指示文テンプレートに自分の監視したいファンド（名前・コード・買い増し条件）を記入する。
3. Museが `SPEC.md` に沿って、空の非公開スペース（ダッシュボード）を試作し、合成データによる計算テストを通す。
4. 出典レジストリ（どの系列をどの公開ソースから取るか）をMuseと確認し、本人の承認後に実データの取得と保存を始める。
5. 取得・保存・読み戻しを検証し、本人の承認後に定期ジョブを登録する。

## ファイル構成

|ファイル|内容|
|---|---|
|SPEC.md|Muse用仕様の正本。画面・永続保存・計算・出典・運用・受入条件|
|PROMPT.md|Museへ最初に渡す指示文のテンプレート|
|config/funds.example.json|ファンド登録の独立した架空例（条件ルールの型カタログは SPEC.md）|
|config/source-registry.example.json|出典レジストリの雛形|
|contracts/daily.template.json|日次契約の雛形（収集対象・上限・指示の構造）|
|contracts/weekly.template.json|週次契約の雛形（固定系列・採点方式の構造）|
|SCRUB-CHECKLIST.md|配布前に個人情報を除去するための確認リスト|

## 設計の要点

- 数値計算はAIの文章生成ではなく、決定的な計算エンジン（合成テストの期待値で検証可能）で行う。AIは公開資料の取得・要約・根拠付き分類だけを担当する。
- 保存は「挿入のみ・既存枠は上書きしない・保存後に別途読み戻して照合」が原則。
- 出典は系列ごとに定義（実銘柄・終値の定義・調整方式・優先/代替経路）を固定したレジストリで管理し、定義の違う代理値を混ぜない。
- ダッシュボードは所有者限定の対話型スペースとし、公開リンクは作らない。
