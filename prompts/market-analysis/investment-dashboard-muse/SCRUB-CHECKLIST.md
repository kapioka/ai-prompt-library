# 配布前スクラブ・チェックリスト

配布物に個人情報を残さないための確認リストです。ZIPを作る前に全項目を確認し、検索でヒットしないことを確かめてください。

## 除去するもの

- [ ] 自分が保有・観察しているファンドの実名と投信コード
- [ ] 実約定NAV、約定日、購入金額、口数などの取引情報
- [ ] 自分の運用方針・資産配分・個人的な判断メモ
- [ ] ダミー名に置換しても残る本人由来の予定金額・閾値・観測期間・段階数・資産分類・条件の組み合わせ（個人の設定から独立した架空例に置換）
- [ ] 実際の設定を類推できる別名、サンプルID、コメント、ファイルのメタデータ、同梱した履歴・バックアップ
- [ ] 認証情報・秘密鍵・APIキー・トークン
- [ ] 実データのスナップショット（価格履歴、実行履歴、読み戻し結果の実数）
- [ ] 元のホスティングのプロジェクトID、URL、アカウント識別子
- [ ] 自分のリポジトリ名・アカウント名への参照（仕様正本へのリンクを含む）
- [ ] チャット履歴や個人的な経緯が分かる記述

## 残してよいもの（汎用情報）

- 計算方法そのもの（採点の重み、警戒の閾値、相関の定義など、手法としての情報）
- 公開市場の系列ID（指数やETFのティッカーなど、誰でも使う市場データの識別子）
- 画面構成、データモデル、アクション分離、運用契約、受入条件といった設計情報
- 独立した架空の記入例（実在しないコードと架空の価格・金額・条件の組み合わせを使う。推奨値・実運用の初期値として扱わない）
- 前身の公開プロンプトへの相対リンク（個人の非公開仕様へのリンクは不可）

## 検索チェックの例

公開対象の全ファイルに対して、自分のファンド名・コード・約定価格・アカウント名・秘密情報を検索する。個人の条件は単語検索だけでなく、予定金額・閾値・期間・資産分類・条件の組み合わせを元の運用設定と照合する。一般的な計算パラメータや公開市場の系列IDとの偶然の一致は、文脈で区別する。配置指示書など公開対象外の作業資料はコミットしない。
