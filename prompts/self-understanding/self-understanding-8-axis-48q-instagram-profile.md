# 自己理解レーダープロファイル — 8軸・48問・Instagram画像生成

48問の4択で8軸の自己評価を整理し、必要に応じて追加質問で具体例を確かめ、**一人ひとり異なる分析文とInstagram向けの縦長1枚画像**を制作する、ChatGPT用のコピペ式プロンプトです。回答の組み合わせ、内面の土台と外へ表れる行動、場面による違いを重視し、定型文への当てはめを避けます。

既存の [自己再発見・自己理解プロンプト集 — 12領域・48種類](self-rediscovery-48-prompts.md) は自由回答型の内省ガイドで、こちらの「8軸×6問」の尺度とは**別形式**です。本プロンプトで出た仮説を深掘りする際の参考として利用できます。

> **位置づけ:** 独自の自己理解ワークです。標準化された心理検査ではなく、統計的な信頼性・妥当性・標準集団に対する偏差は検証されていません。0〜100点は自己回答の尺度換算値であり、能力・適性・人格の優劣を示しません。外から見える行動の軸も、他者評価ではなく本人の自己回答です。

## 想定用途

- 自分の考え方・行動傾向を8軸で視覚化したい
- 結果の背景にある経験や行動を、AIとの対話で深掘りしたい
- Instagram投稿用に、上品な誌面デザインの1080×1350画像を作りたい

## 前提・必要機能

- **必須:** 日本語で対話できるChatGPT
- **画像の完成に必要:** 画像生成または画像ファイル作成に対応した機能
- **厳密なレーダーチャートに推奨:** スコアからSVG等を計算描画できる実行環境。画像生成だけでは多角形・ラベル・数字が一致しない場合があります
- **不要:** 氏名・住所・医療情報・過去の全会話・GitHub接続。ユーザーが必要と考える個別経験以外を要求しない

## 使い方

1. 次の「プロンプト本文」内をすべてコピーして、新しいChatGPTチャットに貼り付ける。
2. 8問ずつ4択で答える（例：4 3 2 4 1 3 4 2）。
3. 必要な追加質問へ回答する。回答したくなければスキップできる。
4. 結果文章を確認し、Instagram向け画像を生成・保存する。画像生成機能やコード実行が使えない場合は、代替出力を利用する。

3. 回答や実例に根拠がない職業適性・家庭環境・他人からの評価・過去の原因を推定しない。
4. 「相対的に控えめな軸」が弱点と決まるわけではない。性格の良し悪しとして評価しない。
5. 上位3軸・下位2軸、特徴的な軸の組み合わせ、内面と外面の接点、強みを発揮しやすい条件、負担の出やすい条件を整理する。
6. 数値が近い軸を無理に順位づけして断定しない。同点や差が小さいことにも意味を持たせる。
7. 褒めることを目的とせず、矛盾しそうな点、別の解釈、反例も扱う。
8. 特徴的な行動例が不足しているときは、不足を明示し、必要な追加質問で確かめる。

10. 結果タイトルや画像の短文も、回答者ごとの根拠に合わせて変える。無理に珍しいタイプ名をつけない。

【採点・正規化】
━━━━━━━━━━━━━━━━━━

- 通常項目：回答値をそのまま使用。
- 逆転項目(R)：5－回答値。
- 各軸6問、合計値は6〜24点。
- 正規化スコアは次式：
  normalized = round(((raw - 6) / 18) * 100)
- 0〜100は本質問票内部の尺度換算であり、平均点・偏差値・母集団のパーセンタイルではない。
- 最終スコアは8軸とも整数。合計・逆転・正規化を再検算する。
- 軸への対応：
  構造化・計画性 = Q1〜Q6
  実行・持続力 = Q7〜Q12
  探索・創造性 = Q13〜Q18
  柔軟・適応性 = Q19〜Q24
  協調・共感性 = Q25〜Q30
  自己主張・境界線 = Q31〜Q36
  感情安定・回復力 = Q37〜Q42
  自己省察・成長志向 = Q43〜Q48

【追加質問】
━━━━━━━━━━━━━━━━━━

48問の結果に応じ、説明をより具体的にできるときのみ最大6問。質問は1問ずつ。本人が断った場合は現在の情報だけで進む。

優先するのは、たとえば次のような点：
- 上位軸と下位軸のギャップが大きく、場面による使い分けを知りたい。
- 計画性と柔軟性、協調性と境界線などの関係が判別しにくい。
- 回答の特徴を裏付ける具体的な行動例が不足している。
- 長所と負担の両方が現れる条件を確認したい。

必要に応じて12領域の視点を使用する：過去、好み・情熱、価値観、役割、強み、感情、思考の癖、対人境界、別の人生、未来、内面との対話、現実の検証。無理に全領域を質問しない。

回答の事実、本人の解釈、AIの仮説を分けて分析する。反例や別の説明も提示する。本人が避けたい過去や私的情報を無理に聞かない。

【最終出力の順序】
━━━━━━━━━━━━━━━━━━

1. 【結果タイトル】日本語の個別タイトルと短い英語サブタイトル。分類ラベルは断定ではなく、その日の自己回答のイメージ。
2. 【注意書き】独自の自己理解ワーク、場面・体調で変動、優劣ではないことを簡潔に表示。
3. 【8軸スコア表】軸名、raw score、0〜100正規化スコア、短い解釈。
4. 【チャートデータ】JSON形式で labels（8軸名）と scores（同じ順に8個の整数）。
5. 【分析の根拠】上位・下位、軸の組み合わせ、内面と外面、具体例の有無、反証・別解釈を6項目前後。
6. 【個別分析】
   - 全体像：3〜6文
   - 内面の土台：4軸の関係
   - 外に表れる行動：4軸の関係
   - 特徴的な組み合わせ：最低2点
   - 強み：3〜5点
   - 負担が出やすい条件：2〜4点
   - 向いている環境の候補：3〜5点
   - 現実で試せる次の一手：2〜4点
7. 【画像掲載用の短文】表紙タイトル、1行サマリー、強み3点、注意点2点、環境3点、注記1〜2行。定型文を使い回さず、根拠のある簡潔な日本語。
8. 【Instagram用の1枚画像】下記のデザインルールで生成する。

【画像デザイン規約】
━━━━━━━━━━━━━━━━━━

画像はInstagram向け縦長4:5、1080×1350pxを基本とする（出力可能なサイズの制限がある場合は4:5を維持し、最終的に適切なサイズへ変換）。

女性誌の特集ページのような上品なエディトリアルデザイン。
- ベース：アイボリー／生成り／淡いグレージュ。
- アクセント：くすみローズ／セージ／やわらかいネイビー／淡いゴールドグレー。
- 大見出しは上品な明朝系、解説は読みやすいゴシック系。英字は細く控えめ。
- 文字の大きさに明確な階層をつくり、十分な余白・行間・段落間を確保する。
- 意味のない巨大英字、薄くて読めない文字、文字の切れ、ラベルの密集を避ける。
- 上部にタイトルと短文、中央付近にレーダーチャート、周囲か下部に解説を整然と配置する。
- 重要なタイトル・チャート・主要解説は、上下が一部トリミングされても残りやすい中央の安全領域に配置。実際のSNSの表示・クロップは一定ではないことに留意する。
- 内容を詰め込み過ぎない。詳細な長文はチャット本文に残し、画像には最も重要な要素だけ載せる。

背景の意味：
- 下段：本人を支える内面の土台。地層、波紋、重なる層、静かな奥行き。
- 中段：内側から外への変換。ゆるやかに上昇する半透明の線やベール。
- 上段：外に表れる行動のイメージ。抜け感、余白、やわらかな光、繊細な粒子。
- 単なる上下の色分けではなく、内面が行動へつながる「流れ」を視覚化する。
- 表現の強弱、図形の重なりなどは実際のスコアや本人の具体例に沿って調整する。根拠のない象徴を断定しない。

チャートの正確さ：
- 8軸の順序を固定、最大値100、全軸同一半径でレーダーを計算描画する。
- 可能なら数値からSVG等で厳密に作成し、背景と合成したPNGを出力する。
- 画像生成機能だけで正しい値・文字・形を保証できない場合、架空のチャートを「正確な結果」として提示しない。正確な数値表を優先し、チャートは正確に生成できる手段があるときのみ掲載する。
- 最終画像に載せるスコアは集計表と一致させる。

## 注意事項

- 質問項目と8軸の分類は、公開用に構成された独自のセルフチェックであり、心理測定学的な検証を受けていません。
- 逆転項目によって回答の偏りを完全に除去できるわけではありません。
- 結果の深掘りに使う [12領域・48種類のプロンプト集](self-rediscovery-48-prompts.md) は独立した資料であり、本チェックの正式な測定根拠ではありません。
- 生成画像の正確性は利用可能な機能に依存します。画像生成単独で数値やラベルが厳密に再現されるとは限りません。
- 個人的な体験や人間関係は、必要最小限・匿名化した情報だけを共有してください。
