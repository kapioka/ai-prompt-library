# ChatGPT へ渡す指示文

以下を、この資料フォルダ（README.md と docs/ 一式）と一緒に ChatGPT に渡してください。

---

あなたは Web アプリ開発者です。添付資料をもとに、Apex Legends のマップローテーション確認アプリを GitHub 公開用に再実装してください。

## 作るもの

- モード別（ランク／バトルロイヤル／ミックステープ／ワイルドカード）に「現在のマップ」「残り時間のカウントダウン」「次のマップ」「以後数件の予定（予測は予測と明示）」を表示する Web アプリ
- ミックステープはモード種別（チームデスマッチ／コントロール／ガンゲーム）＋マップ名で表示する。導出方法と安全策は `docs/DATA.md` の通りとし、マップ名が対応表と一致しない場合はモードを表示しないこと
- お気に入りマップの登録（localStorage で可）と、ライブ中の強調表示
- Apex公式アップデートの最新5件を画面下部に表示すること。取得は X ではなく Steam News 公式API（キー不要）を使うこと。エンドポイントと項目、注意点は `docs/UPDATES.md` の通り
- お気に入りマップの開始前通知の設定UI（ON/OFF、何分前かをプリセット＋任意入力、対象モード）。通知の実行はホスト側の定期チェックと分担する設計にし、設定は保存すること
- データ取得は `docs/DATA.md` の方法（apexdb.gg の埋め込みデータ、15分間隔）を使い、表示時は保存済みデータを即返して外部取得で待たせない構成にすること（`docs/ARCHITECTURE.md` 参照）

## デザイン（重要）

- 配色・レイアウト・ロゴは、本プロジェクトのデザイン指針に基づいて作成すること
- デザインは `docs/DESIGN.md` の「Muse仕様」に従うこと：オフホワイト基調、アクセント単色（コーラル系）、白カード＋細い罫＋小さなチップ、4モードを2×2タイルで一画面に収めるダッシュボード型グリッド構成（NEXT／NEXT 2／NEXT 3 の3行表示）、数字だけ大きく、説明は短いラベルだけ
- 非公式ファンメイドであり EA / Respawn と無関係である旨と、データ出典（Apex Legends Status / apexdb.gg）を画面下部に明記すること
