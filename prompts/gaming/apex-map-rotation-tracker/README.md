# Apex マップローテーション — 公開用プロジェクト資料

Muse を使って、Apex Legends のマップローテーション（現在のマップ・残り時間・次のマップ）や公式アップデート情報を、ゲームを起動せずに手軽に確認できるものを目指して作った小さな Web アプリです。
Muse のスペース（個人用アプリ基盤）上で動作するアプリの仕様・設計・データ取得方法を、誰でも再実装できる形で公開用にまとめた資料セットです。

> これは非公式のファンメイドツールです。Electronic Arts Inc. / Respawn Entertainment とは関係ありません。

## できること

- モード別（ランク／バトルロイヤル／ミックステープ／ワイルドカード）の「現在のマップ」と「切り替わりまでの残り時間」をカウントダウン表示
- 次以降のローテーション予定を表示（先のスロットは予測として区別）
- ミックステープはモード種別（チームデスマッチ／コントロール／ガンゲーム）＋マップ名で表示
- お気に入りマップの登録（保存され、ライブ中は強調表示）
- データは15分ごとに自動取得、手動更新ボタンもあり
- Apex公式アップデートの最新情報を表示（EA Japan の日本語記事と Steam News の英語記事を各最大3件。Xに依存しない。`docs/UPDATES.md` 参照）
- お気に入りマップの開始前通知（何分前かを任意に設定可能。通知の実行はホスト側の定期チェックと分担する設計。Muse版では Muse の定期チェックがチャットへ通知する）

## できないこと

- プレイヤー統計やサーバーステータスなどの表示（対象外）
- スペース単体でのプッシュ通知（通知はホスト側の仕組みと組み合わせて実現する）

## Muse での使い方

1. このフォルダ一式を取得します。GitHub の Code → Download ZIP でリポジトリ全体を取得し、`prompts/gaming/apex-map-rotation-tracker/` だけを取り出しても構いません。
2. フォルダ構成を保ったまま資料一式を ZIP にまとめ、自分の Muse に添付します。
3. [PROMPT_FOR_MUSE.md](PROMPT_FOR_MUSE.md) の指示文を Muse に渡し、利用中の環境でフルスタック・スペース、永続保存、サーバーアクション、定期ジョブ、チャット通知が利用できるか確認します。
4. Muse に自分用のスペースを構築してもらい、画面、取得・保存、カウントダウン、お気に入り、公式ニュースの表示を確認します。
5. 実データ取得と保存・読み戻しの検証後、利用者の承認を得て15分間隔の定期ジョブを登録します。お気に入り通知は既定OFFとし、必要な場合だけ利用者が有効化します。

この資料は完成アプリの配布ではなく、Muse に再実装させるための仕様・プロンプト集です。対応機能や利用制限は利用環境によって異なります。利用できない機能は未対応として報告し、無断で外部サービス・有料APIを追加しません。
