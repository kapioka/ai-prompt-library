# Apex マップローテーション — 公開用プロジェクト資料

Muse を使って、Apex Legends のマップローテーション（現在のマップ・残り時間・次のマップ）や公式アップデート情報を、ゲームを起動せずに手軽に確認できるものを目指して作った小さな Web アプリです。
Muse のスペース（個人用アプリ基盤）上で動作するアプリの仕様・設計・データ取得方法を、誰でも再実装できる形で公開用にまとめた資料セットです。

> これは非公式のファンメイドツールです。Electronic Arts Inc. / Respawn Entertainment とは関係ありません。

## できること

- モード別（ランク／バトルロイヤル／ミックステープ／ワイルドカード）の「現在のマップ」と「切り替わりまでの残り時間」をカウントダウン表示
- 次以降のローテーション予定を表示（先のスロットは予測として区別）
- ミックステープはモード種別（チームデスマッチ／コントロール／ガンゲーム）＋マップ名で表示
- お気に入りマップの登録（保存され、ライブ中は強調表示）
- データは15分ごとに自動取得、手動更新ボタンもあり
- Apex公式アップデートの最新情報を表示（Xではなく Steam News 公式APIから取得。`docs/UPDATES.md` 参照）
- お気に入りマップの開始前通知（何分前かを任意に設定可能。通知の実行はホスト側の定期チェックと分担する設計。Muse版では Muse の定期チェックがチャットへ通知する）

## できないこと

- プレイヤー統計やサーバーステータスなどの表示（対象外）
- スペース単体でのプッシュ通知（通知はホスト側の仕組みと組み合わせて実現する）
