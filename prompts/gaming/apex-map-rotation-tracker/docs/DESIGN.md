# デザイン指針 DESIGN

## 大原則：情報を一目で確認できる独自デザインにする

現在のマップと残り時間、次の予定を短時間で把握できるよう、視認性とコンパクトな情報配置を重視する。

### 本プロジェクトの表現（Muse仕様）

- **背景**：オフホワイト基調の明るい画面
- **アクセント**：単色のみ（温かみのあるコーラル系）。モードごとの色分け塗りはしない
- **カード**：白背景＋細い罫線＋小さなチップ（モード名・状態表示）で情報を区切る
- **構成**：ダッシュボード型グリッド。4モードを 2×2 のタイルで一画面（ファーストビュー）に収め、詳細はタイルのタップで展開する。モードを縦に積んだリスト構成は採らない
- **タイポグラフィ**：残り時間の数字だけを大きくし、マップ名は中見出し、説明は短いラベルに留める
- **ミックステープ**：モード種別を主表示にし、マップ名を添える（例：コントロール／生産工場）

## レイアウトスケッチ（テキスト）

```
[タイトル]  [取得時刻]        [更新]

┌─────────────┬─────────────┐
│ [ランク]  ★ │ [バトルロイヤル] ★ │
│ E-ディストリクト │ ストームポイント │
│ あと 1:23:45 │ あと 0:41:02 │
│ ▓▓▓▓░░░░    │ ▓▓░░░░░░    │
│ 次: ブロークンムーン 15:30 │ 次: E-ディストリクト … │
├─────────────┼─────────────┤
│ [ミックステープ] ★ │ [ワイルドカード] ★ │
│ コントロール/生産工場 │ ストームポイント │
│ あと 0:09:28 │ あと … │
│ 次: ガンゲーム/スカルタウン │ 次: オリンパス … │
└─────────────┴─────────────┘
（タイルをタップ → そのモードの今後の予定をグリッド下に展開）

[お気に入り＆通知設定の帯]
[公式アプデ（最新3件・1行リスト）の帯]
```

- 各タイルにはスロットの経過率を示すプログレスバーを置く（開始からの経過割合）
- お気に入りがライブ中のタイルは枠をアクセント色で強調し、LIVEチップを付ける

## アクセシビリティ・表示の注意

- 残り時間は `tabular-nums` 等で桁ブレさせない
- 色だけに頼らず、状態は文字ラベル（LIVE／予測など）でも示す
- ダークモード端末でも破綻しないよう、背景と文字のコントラストを確保する
